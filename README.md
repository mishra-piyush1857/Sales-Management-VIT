# Smart Inventory and Sales Management

A small Java console application for managing products, stock levels, and sales without a database. Product and sales data are loaded from text files when the application starts and saved after changes are made.

## Features

- Add, view, search, update, and delete products
- Record sales and automatically reduce available stock
- Calculate the total amount for each sale
- View sales history, including the date and time of each sale
- Generate a low-stock report
- Persist data in plain text files
- Validate numeric input and reject sales that exceed available stock

## Requirements

- Java Development Kit (JDK) 17 or later
- A terminal and any Java-capable editor or IDE
- No external libraries or database server

## Getting Started

Run these commands from the project root so the application can find the `data/` directory:

```bash
javac -d out src/*.java
java -cp out Main
```

On Windows PowerShell, the same commands work as written. The `out` directory is generated by the compiler and can be removed whenever a clean build is needed.

## Menu Options

Once the application starts, choose an option from the main menu:

1. **Add Product** - Create a product with an ID, name, category, price, quantity, and minimum stock level.
2. **View All Products** - Display every product and its current stock.
3. **Search Product** - Find a product by ID.
4. **Update Product** - Replace the name, category, price, quantity, or minimum stock level for an existing product.
5. **Delete Product** - Remove a product after confirmation.
6. **Record Sale** - Record a sale for an existing product and decrease its quantity.
7. **View Sales** - Display all recorded sales and their totals.
8. **Low Stock Report** - List products whose quantity is less than or equal to their minimum stock level.
9. **Exit** - Close the application.

Product IDs are matched without regard to letter case. A sale must have a positive quantity and cannot exceed the product's available stock.

## Data Files

The application uses pipe-delimited text files. Do not add a header row.

### `data/products.txt`

Each line has six fields:

```text
productId|productName|category|price|quantity|minimumStock
```

Example:

```text
P001|Laptop Pro|Electronics|65000.0|2|2
```

### `data/sales.txt`

Each line has seven fields:

```text
saleId|productId|productName|quantity|pricePerUnit|totalAmount|dateTime
```

New sales use the timestamp format `yyyy-MM-dd HH:mm:ss`. Records with invalid numeric fields are skipped when loading.

## Implementation Notes

- `Main` provides the interactive console menu and input handling.
- `InventoryManager` contains product and sale operations.
- `FileManager` handles persistence in `data/products.txt` and `data/sales.txt`.
- `Product` and `Sale` are the application's data models.
- The application uses Java collections, file I/O, exception handling, and the Java Date and Time API.
